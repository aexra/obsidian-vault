## Общее
Основная идея заключается в том, чтобы юзер вписывал адрес сервера, клиент отправлял запрос(ы) на сервер (-ы, на случай если API уже будет иметь несколько версий), и если сервер откликается, то можно добавить этот сервер в конфиг (войти грубо говоря). Серверов может быть в подключении много.

> [!info]
> Серверу и клиент не обязательно соответствовать. Если клиент предназначен для другой сборки провайдера, это проблемы клиента, возможно ему нужно обновиться или скачать клиент из другого репозитория.
### Страницы клиента
Под страницами клиента подразумеваются вкладки, которые будут доступны пользователю вне зависимости от сервера, даже без наличия любого из них.

> [!tip] Idea
> Возможно, стоит рассмотреть идею реализации личного хранилища на базе [SQLite](https://www.sqlite.org/) для отражения локальной ФС и хранения там данных с мета-инфой для страниц-дашбордов хранилищ


### Страницы сервера
Под страницами сервера подразумеваются вкладки, которые будут доступны пользователю на каждом сервере.
