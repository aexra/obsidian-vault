## Общее
Основная идея заключается в том, чтобы юзер вписывал адрес сервера, клиент отправлял запрос(ы) на сервер (-ы, на случай если API уже будет иметь несколько версий), и если сервер откликается, то можно добавить этот сервер в конфиг (войти грубо говоря). Серверов может быть в подключении много.

![[Features list 2025-07-22 10.18.35.excalidraw | center]]

> [!info]
> Клиенту и провайдеру не обязательно соответствовать. Если клиент предназначен для другой сборки провайдера, это проблемы клиента, возможно ему нужно обновиться или скачать клиент из другого репозитория. Работать будет то, что работает.
### Страницы клиента
Под страницами клиента подразумеваются вкладки, которые будут доступны пользователю вне зависимости от сервера, даже без наличия любого из них.

> Возможно, стоит рассмотреть идею реализации личного хранилища на базе [SQLite](https://www.sqlite.org/) для отражения локальной ФС и хранения там данных с мета-инфой для страниц-дашбордов хранилищ. По факту там будет храниться только некая индексация и прочие плюшки типа тегов.

### Страницы сервера
Под страницами сервера подразумеваются вкладки, которые будут доступны пользователю на каждом сервере в рамках данной сборки клиента.

#### Личные страницы
Под личными страницами подразумеваются страницы, которые будет видеть только текущий пользователь (его личные страницы).

#### Общие страницы
Под общими страницами подразумеваются страницы, доступные для общего использования (чаты, общие хранилища и т.п.).
